OUR LITTLE WORLD - GitHub Pages website

1. Upload index.html to the root of your GitHub repository.
2. Upload the entire images folder (all 32 photo-XX.jpg files) to the same repository root.
3. Keep the folder name exactly "images".
4. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Wait a few minutes; your website URL will appear in Settings > Pages.

The website is one copy-paste-ready index.html file plus the images folder. Music is generated as an original soft instrumental in the browser after the visitor taps Play music. Audio autoplay is blocked by most browsers until a user gesture. All letters and headings can be edited inside the C object in the script near the bottom of index.html.

This is a public static website. Anyone with the link can view the uploaded photos and letters.
